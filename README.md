\# Autonomous AI Agent for Task Extraction and Workflow Execution



An intelligent AI agent that automatically reads emails from Gmail, extracts actionable tasks, decides workflows, executes actions, and generates outputs with minimal human intervention.



\## 🎯 Project Overview



This project builds an autonomous agent system that leverages Large Language Models (LLMs) to understand natural language, make intelligent decisions, and execute multi-step workflows. Unlike traditional rule-based automation, this system uses agentic workflow automation.
