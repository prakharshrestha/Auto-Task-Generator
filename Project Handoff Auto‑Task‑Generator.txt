✅ Key Code Files (what they do)
backend/main.py
FastAPI startup entry.
Loads settings, sets logging, includes routers.
backend/config.py
Environment variable loader.
All secrets pulled from .env.
If you add new configs, add them here.
backend/app/routes/auth.py
OAuth login and callback endpoints.
Handles token storage.
backend/app/routes/gmail.py
Main API endpoints for Gmail.
Supports mode=raw, mode=extract, mode=plan.
Cleans email body length for LLM.
backend/app/services/gmail_service.py
Calls Gmail API to get emails.
Extracts subject/body/sender.
backend/app/services/llm_service.py
Calls Ollama /api/chat
Adds num_predict limit for speed.
Used by task_agent.py.
backend/app/agents/task_agent.py
The brain:
Calls LLM to extract tasks
Calls LLM to plan steps
Returns structured output
✅ How the current flow works
Client hits:
Code
/api/gmail/recent-plans?mode=plan
Gmail API fetches latest messages
Email text trimmed (clean body)
LLM called for extraction
If mode=plan, LLM called again for reasoning
Result returned as JSON
✅ Why “plan mode” is slow
It runs 2 LLM calls per email
Local CPU inference takes time
